Faroese translation of Heroes of Might and Magic III for VCMI.

Translations are made on [Weblate](https://weblate.vcmi.eu/) and synchronized into this repository automatically — please don't edit files under `content/config/vcmi-faroese` directly.

The documentation for translation is [here](https://github.com/vcmi/vcmi/blob/develop/docs/translators/Translations.md).

Please create a new issue [here](https://github.com/vcmi-mods/faroese-translation/issues/new) for any mistake.
